# Scaffold @atlure/ui as a source-shipping package

## Context

`@atlure/ui` holds the React Native components. It must ship **untranspiled TypeScript source**, not a compiled build. NativeWind 4's `className` support is a Babel-time JSX transform (`jsxImportSource: "nativewind"`); precompiling to `react/jsx-runtime` — which `react-native-builder-bob`'s module target does — turns `className` into a dead prop and every component renders unstyled with no error. This is the single most likely way to break the whole design system, and the predecessor's `0.0.40` shipped a broken `exports` map pointing at a file that did not exist.

## Scope

- Create `packages/ui` publishing `@atlure/ui`. **No build step.** No `react-native-builder-bob`, no `tsc` emit for the shipped code.
- `package.json`: `main` and `exports` both point at `src/index.ts`. `"source": "src/index.ts"`. `files: ["src", "README.md"]` — nothing else.
- Dependencies: only `@atlure/types` and `@atlure/tailwind-preset`. `react`, `react-native`, `nativewind`, `expo` and `tailwindcss` are **peerDependencies**, not dependencies — the predecessor put the whole Expo stack in `dependencies`.
- No `app/` directory, no `expo-router` dependency, no `app.config.js`, no `.storybook/`, no `.rnstorybook/`, no `*.stories.*` in the package. Storybook lives in `apps/` (ticket 025).
- `babel.config.js` in the package for local tests only, marked as not published.
- `cn()` utility (clsx + tailwind-merge) and the shared `cva` recipe module that `@atlure/ui-web` will also import, restricted to the RN-safe Tailwind subset.
- README documenting loudly that consumers must extend `@atlure/tailwind-preset` and that the package is source, so Metro must transpile it.

## Out of scope

Any actual component — epic `ds-native`. The pack-manifest test (ticket 023). Publishing (ticket 022).

## Files you own

`packages/ui/package.json`, `packages/ui/tsconfig.json`, `packages/ui/babel.config.js`, `packages/ui/README.md`, `packages/ui/src/lib/cn.ts`, `packages/ui/src/lib/recipes/`.

## Files you must NOT touch

`packages/tokens/**`, `packages/tailwind-preset/**`. Do not create `packages/ui/src/index.ts` by hand — it is glob-generated by ticket 020.

## Acceptance criteria

1. `node -e "const p=require('./packages/ui/package.json'); if(p.exports['.'] !== './src/index.ts') process.exit(1)"` exits 0.
2. `node -e "const p=require('./packages/ui/package.json'); for (const d of ['react','react-native','nativewind','expo']) if (p.dependencies?.[d]) process.exit(1)"` exits 0.
3. `cd packages/ui && npm pack --dry-run --json` lists only paths under `src/`, plus `package.json` and `README.md`. No `.stories.`, no `.storybook`, no `output/`, no `app/`.
4. `pnpm --filter @atlure/ui typecheck` exits 0.
5. Every path named in `exports` resolves: `node -e "const p=require('./packages/ui/package.json'); const fs=require('fs'); for (const v of Object.values(p.exports)) fs.accessSync('packages/ui/'+(typeof v==='string'?v:v.default))"` exits 0. This is the direct guard against the `0.0.40` defect.
