Add the native form control set: `Textarea` with a row-based minimum height and an optional character counter, `FormField` composing label, control, helper and error text, `SearchBar` with a debounced change callback and a clear affordance, and `FormScrollView` for keyboard avoidance. `Input` gains leading and trailing icon slots, a token-driven placeholder colour, and automatic label association, invalid, required and disabled state when rendered inside a `FormField`. `@atlure/ui` now depends on `@atlure/icons`, so consumers need `react-native-svg` installed.
